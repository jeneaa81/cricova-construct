# 🚗 ENORM Telegram Bot (AI & 1C Prototype)

Интеллектуальный Telegram-бот для магазина автозапчастей **ENORM.md** (S.R.L. "RA UNITED TRADE", г. Криково / мун. Кишинёв).

Разработан как готовый рабочий прототип для демонстрации собственнику магазина возможностей автоматизации розничных продаж, сокращения рутины подбора по VIN и интеграции с 1С.

---

## 🌟 Ключевой функционал

1. **AI-распознавание техпаспорта автомобиля (OCR / Gemini Vision):**
   - Клиент отправляет фотографию молдавского/румынского/украинского техпаспорта (СТС).
   - Нейросеть мгновенно считывает: VIN-код (17 знаков), марку, модель, год выпуска и двигатель.
   - Исключаются опечатки и ошибки ручного ввода.

2. **Живой поиск по каталогу enorm.md в реальном времени:**
   - Клиент вводит артикул (например: `OC90`, `W712`, `32122`).
   - Бот на лету опрашивает базу сайта `enorm.md`, получает цены в леях (MDL) и реальные складские остатки (*«В наличии Кишинёв»*, *«Под заказ 1-3 дня»*).

3. **Связка с 1С:Предприятие (1C Export Engine):**
   - Каждая созданная заявка автоматически транслируется в стандартизированный пакет обмена EnterpriseData / JSON и сохраняется в каталог `exports_1c/`.
   - Готово к прямой передаче в 1С:Управление торговлей или 1С:Альфа-Авто через HTTP-сервис.

4. **Мультиязычность:**
   - Полная поддержка интерфейса на Русском (🇷🇺) и Румынском (🇲🇩 Română).

5. **Оповещение менеджера в рабочий чат:**
   - При оформлении заказа в закрытую группу менеджеров магазина падает готовая карточка с кликабельным VIN и контактами клиента.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
Все библиотеки уже установлены в среде. При необходимости:
```bash
pip install python-telegram-bot aiosqlite python-dotenv requests google-genai
```

### 2. Настройка токена
1. Откройте Telegram и напишите боту **`@BotFather`**.
2. Введите `/newbot`, укажите имя (например, `Enorm Auto Demo`) и юзернейм (например, `enorm_demo_bot`).
3. Скопируйте полученный токен.
4. Создайте файл `.env` в папке `enorm_bot` (или скопируйте из `.env.example`):
   ```env
   TELEGRAM_BOT_TOKEN=123456789:AAFxxyyzz...
   MANAGER_CHAT_ID=
   GEMINI_API_KEY=
   ```

### 3. Запуск бота
```bash
python run_bot.py
```

## 📁 Структура проекта

```
enorm_bot/
├── config.py              # Конфигурация и данные магазина
├── run_bot.py             # Точка входа и запуск polling
├── database/
│   └── db.py              # SQLite хранилище заявок и пользователей
├── handlers/
│   ├── start.py           # Главное меню и переключение языков
│   ├── catalog_search.py  # Живой поиск по сайту enorm.md
│   ├── vin_request.py     # Пошаговый мастер подбора по VIN / фото
│   └── info.py            # Контакты магазина в Криково и доставка
├── services/
│   ├── enorm_catalog.py   # Парсер поиска enorm.md
│   ├── vin_ocr.py         # Модуль AI Vision для распознавания техпаспортов
│   └── order_export_1c.py # Генератор пакетов обмена для 1С
└── exports_1c/            # Каталог сгенерированных заказов для 1С
```

## 🎯 Сценарий демонстрации владельцу (Валентину Райляну)

1. **Шаг 1: Живой поиск цен**
   - Введите в боте артикул `OC90`.
   - Покажите, что бот за 0.5 секунды выдал актуальную цену 70 MDL и наличие со склада enorm.md.
2. **Шаг 2: Подбор по фото**
   - Нажмите *«🔍 Подбор запчастей по VIN / Фото»*.
   - Отправьте фото любого техпаспорта.
   - Покажите, как за 2 секунды распознался VIN и модель авто.
3. **Шаг 3: Мост в 1С**
   - Оформите заказ и откройте папку `exports_1c/`.
   - Покажите сформированный JSON/XML: *«Валентин, вашему менеджеру не нужно руками перебивать заказы в 1С — они сразу падают в учетную систему готовым документом!»*.
